Privacy Policy

Last updated: 18 November 2026

Data the tool uses

  • The TikTok access token for the owner's own account, used only to upload the owner's videos. It is stored locally on the owner's computer and is never shared or sold.
  • Basic account information (open ID and display name), used only to confirm that the right account is connected.

Data the tool does not collect

The tool does not collect, store or process data about any other TikTok user, viewer or follower. It reads no messages, contacts or analytics, and it has no tracking, cookies, advertising or third-party sharing.

Retention and removal

The access token is kept only while the tool is in use and can be revoked at any time in TikTok's settings (Manage app permissions). Deleting the local token file removes all stored data.
